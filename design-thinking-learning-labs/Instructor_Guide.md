# Instructor Guide — Design Thinking Learning Lab

The six self-contained labs reinforce design thinking from empathy through iterative testing. Each lab may be hosted in a different Canvas module. Use consistent case choices for continuity.

## Scenarios
- **Jordan, campus events:** Jordan is a commuter student deciding when staying on campus for an event is worthwhile; timing, waiting gaps and social context may matter more than advertising.
- **Elena, customer experience:** Elena navigates an online-order pickup journey at Riverbend Home & Garden, encountering questions about arrival, signage, order confirmation and handoff.

## Learning goals by lab
1. **Interview Simulator:** Use non-leading, experience-based questions and gather observable evidence.
2. **Problem Framing:** Separate findings from assumptions, identify patterns, revise a problem statement, write a How Might We question.
3. **Idea Generation:** Use multiple divergent ideation strategies and respond to constraints.
4. **Idea Selection:** Compare desirability, feasibility, accessibility and testability; explain tradeoffs.
5. **Rapid Prototyping:** Create an editable, low-fidelity service journey and identify the assumption it tests.
6. **Test & Iterate:** Interpret simulated feedback, revise and retest; distinguish model feedback from actual user data.

## Suggested workflow
Allow approximately 20–40 minutes per lab, adjusting for class discussion. Students choose one scenario, export a JSON evidence/progress file, then import the file into the next lab. Require a brief written justification and the HTML learning artifact at suitable checkpoints. Students who missed an earlier lab can use supplied sample evidence.

## Assessment guidance
Use a formative rubric with four dimensions (0–3 each): evidence quality, reasoning and assumptions, meaningful design choices, and reflective iteration. Reward defensible reasoning, not a single predetermined solution.

## Cautions
Both users and results are fictional. The simulated testing exercise supports practice but never replaces research with real stakeholders. See Accessibility_Report.md before deploying in Canvas.
